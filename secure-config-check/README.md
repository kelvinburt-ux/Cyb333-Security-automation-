# Secure Config Check

A Python-based, read-only security auditing tool that evaluates Ubuntu 24.04 LTS configurations against 15 selected CIS Level 1 Server recommendations.

## Development Status

Core development is has been completed. This project includes 15 CIS-aligned checks, a command-line interface, console reporting, JSON reporting, and safe error handling. All 144 automated tests pass on Windows and Ubuntu 24.04.

Documentation, screenshots, Ubuntu audit evidence, and the final project review are currently in progress.
